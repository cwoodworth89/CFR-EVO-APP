## 💾 Database Schema: `init_db.sql`

The local PostgreSQL database maintains full JSONB and array compatibility with the original schema across three tables:

### 1. Primary Table: `live_calls`

```sql
CREATE TABLE IF NOT EXISTS public.live_calls (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dispatch_id TEXT UNIQUE NOT NULL,
    timestamp TIMESTAMPTZ DEFAULT TIMEZONE('utc', NOW()) NOT NULL,
    
    incident_type TEXT NOT NULL DEFAULT 'Unknown Incident',
    responding_units TEXT[] NOT NULL DEFAULT '{}',
    
    target JSONB NOT NULL DEFAULT '{
        "address": "Unknown Location",
        "subaddress": null,
        "lat": null,
        "lng": null,
        "rings": [],
        "radio_channel": null,
        "map_grid": null,
        "verified_talkgroup": null,
        "verified_map_grid": null,
        "tone_name": null,
        "include_in_training": false
    }'::jsonb,
    
    raw_transcript TEXT,
    sanitized_transcript TEXT,
    confidence_score NUMERIC(5,2) DEFAULT 0.0,
    verify_location BOOLEAN DEFAULT FALSE,
    origins TEXT[] DEFAULT '{}',
    
    audio_url TEXT,
    audio_duration NUMERIC(6,2),
    
    verified_transcript TEXT,
    verified_address TEXT,
    verified_incident TEXT,
    verified_units TEXT[],
    feedback_submitted BOOLEAN DEFAULT FALSE,
    quality_rating TEXT DEFAULT 'PENDING',
    model_updated BOOLEAN DEFAULT FALSE,
    review_notes TEXT
);

CREATE INDEX IF NOT EXISTS idx_live_calls_timestamp ON public.live_calls (timestamp DESC);
CREATE INDEX IF NOT EXISTS idx_live_calls_feedback ON public.live_calls (feedback_submitted, verify_location);
```

### 2. Secondary Table: `evaluation_history`

```sql
CREATE TABLE IF NOT EXISTS public.evaluation_history (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc', NOW()) NOT NULL,
    model_version TEXT NOT NULL,
    total_samples INTEGER NOT NULL,
    wer NUMERIC(5,2) NOT NULL,
    cer NUMERIC(5,2) NOT NULL,
    perfect_percent NUMERIC(5,2) NOT NULL,
    operational_percent NUMERIC(5,2) NOT NULL,
    failed_percent NUMERIC(5,2) NOT NULL
);
```

### 3. Queue Table: `dispatch_uploads`

```sql
CREATE TABLE IF NOT EXISTS public.dispatch_uploads (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc', NOW()) NOT NULL,
    audio_url TEXT NOT NULL,
    verified_transcript TEXT,
    status TEXT DEFAULT 'pending' NOT NULL,
    result JSONB,
    error_message TEXT
);
```

## 📡 API & Real-Time Endpoints

### 1. REST Endpoints (FastAPI Gateway - Port 8000)
- `GET /api/dispatches`: Queries dispatches for Kiosk map board and Admin Dashboard.
- `POST /api/dispatches`: Inserts or updates dispatch, triggering Mosquitto MQTT publish to `cfr/dispatches`.
- `PATCH /api/dispatches/{id}`: Submits HITL admin corrections.
- `DELETE /api/dispatches/{id}`: Deletes dispatch record.
- `GET /api/evaluations`: Retrieves STT evaluation history.
- `GET /api/audio/{filename}`: Serves WAV recordings from `backend/audio_files/recordings/`.
- `POST /api/auth/login`: Issues JWT tokens for Admin Review Dashboard login.

### 2. Real-Time MQTT WebSockets (Mosquitto - Port 9001)
- **Topic**: `cfr/dispatches`
- **Protocol**: MQTT over WebSockets (`ws://<server-ip>:9001`)
- **Event Payload**:
  ```json
  {
    "eventType": "INSERT",
    "new": {
      "dispatch_id": "DISP-2026-16D402",
      "incident_type": "Structure Fire",
      "target": { "address": "2648 Sandstone Cres", "lat": 49.28, "lng": -122.80 },
      "audio_url": "/api/audio/DISP-2026-16D402.wav"
    }
  }
  ```

## 🚚 Smart Audio Sync & Data Migration

To import historical entries from cloud Supabase and preserve existing local audio files:

```bash
python backend/scripts/migrate_supabase_to_local.py
```

- **Audio File Preservation**: Scans `backend/audio_files/recordings/` first. Compares `dispatch_id` WAV filenames against Supabase Storage and only downloads missing audio files.
- **Relative Path Serving**: Stores audio URLs as relative paths (e.g., `/api/audio/DISP-2026-16D402.wav`), ensuring IP-agnostic rendering across all 4 station kiosks.
